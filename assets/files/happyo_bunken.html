発表の視覚支援 文献の調べと使い方

4年理科「物の体積と温度」　2026年10月7日　発表のカードとスライドの2回目に合わせて作成

この資料の目的　子どもが前に立って、予想や班で話し合ったことを説明するときの視覚支援を、特別支援教育の文献で確かめ直しました。そのうえで、1回目のカードとスライドを作り直しました。

結論　視覚支援を用意する方向は、文部科学省の資料と海外の研究の両方で支持されています。直したのは次の6点です。

  1. 色だけに頼らず、段階ごとに番号と形をつけました。
  2. 一度に見せる量を、その時間の段階のカードだけにしました。
  3. 話し方の型は、外していく順番を先に決めました。
  4. 班（5〜6人）の準備を、ひとり、となり、班、全体の順にしました。
  5. 聞く子も全員が反応できるよう、反応カードを足しました。
  6. 指さしや書画カメラで見せることも、説明のしかたとして認めました。

1 調べて分かったこと

(1) 視覚支援は、根拠のある方法とされています

米国の自閉スペクトラム症の実践研究の総まとめ（NCAEP 2020）は、972本の研究から28の方法を、根拠のある実践として認めています。視覚支援はその1つです。小学生では、学業を含む多くの成果で支持されています。ただし対象は自閉スペクトラム症の子どもで、多くは少人数の研究です。

日本の公的な資料では、文部科学省のガイドライン（平成29年）が、全ての子に有効な授業の工夫として、学習の流れを目に見える形にすること、話し方や聴き方を示すことを挙げています。学習指導要領解説 理科編（96〜97ページ）も、実験の手順や方法を視覚的に表したプリントを掲示したり配ったりする配慮を例に挙げています。同じページで、学習内容の変更や学習活動の代替を安易に行わないよう求めています。カードは考える手がかりであり、考える部分を肩代わりする物ではない、という位置づけになります。

(2) 色だけで区別させない

色覚に多様性のある子は、男子のおよそ5％、女子のおよそ0.2％です（文部科学省「色覚に関する指導の資料」）。1学級にほぼ1人いる割合です。この資料と日本眼科医会の資料は、次のことを求めています。

  • 色以外の情報（形、文字、記号、線）を必ず添える。
  • 白黒でコピーしても見分けられるか確かめる。
  • 黒板の字は白と黄を主にする。赤チョークは見えにくい。
  • 「赤のカード」のように色の名前で指示しない。

1回目の5色（赤、だいだい、緑、紺、むらさき）には、見分けにくいとされる組み合わせ（赤と緑、紺とむらさき）が入っていました。色覚の見え方を計算でまねて比べたところ、2回目の配色では、いちばん近い2色の差が1回目の約2倍になりました。

(3) 一度に見せる量を絞る

「障害のある子供の教育支援の手引」（令和3年）は、視覚的な情報を足すことと同時に、似た情報が混ざると必要な情報を選びにくいこと（学習障害の章 295ページ）、黒板の周りの掲示物を減らすこと（注意欠陥多動性障害の章 314・317ページ）も書いています。授業のユニバーサルデザインの側からも、必要のない視覚化への注意が出ています（村田 2016）。海外では、壁の掲示が多い教室で幼児の注意がそれやすく、学習の伸びが小さかったという実験があります（Fisher ほか 2014）。授業に関係するカードや4年生で確かめた研究ではないので、この点は推論です。

(4) 話し方の型は、外していく前提で使う

話し方の型の掲示だけを取り出して効果を比べた研究は、日本でも海外でも見つかりませんでした。一方で、型を段階的に外していくと、型のない場面でも話せるようになったという研究があります。

  • 型の文を、文の終わりから少しずつ消していくと、型なしの発話が増え、ほかの場面にも広がった（Krantz と McClannahan 1993、宮崎ほか 2012）。
  • 中学1年の理科で、説明の手がかりを途中から減らした群は、手がかりのない課題で理由をよく書けた（McNeill ほか 2006）。
  • 型を見せ続けると、型の中の発話は増えるが、型の外の発話は伸びにくかった例もある（Ganz ほか 2008）。

新潟県教育委員会の事例（令和5年）も、少ない言葉の手がかりから始め、ノートに書いてからペアや小グループで話す支援を示しています。

(5) 準備を段階にし、説明のしかたを選べるようにする

国立特別支援教育総合研究所は、筋道を立てて話すのが苦手な子には、話すことを先に書いてから発表させることを挙げています。班での話し合いが苦手な子もいるので、ひとりで書く、となりの人に言う、という段階を前に置くと参加しやすくなります（伊藤 2016）。中学生の研究ですが、ひとりで考え、ペアで話してから全体で話すと、挙手が増えたという報告もあります（Mundelsee と Jurkowski 2021）。指さしや書画カメラ、絵で示すことも、話す説明と同じ正式な方法として認めることが、学びのユニバーサルデザインの指針（CAST 2024）に合います。

(6) 聞く子も、全員が反応できるようにする

全員がカードを上げて答える方法（反応カード）は、挙手と比べて、参加とテストの成績が上がり、課題から外れる行動が減りました（Randolph 2007、18本の研究のまとめ）。更新された分析でも、特別支援教育の子と通常の学級の子のどちらにも効果がありました（Marsh ほか 2023）。手引も、通常の学級で意思表示カードを使う例を挙げています（注意欠陥多動性障害の章 317ページ）。本時の全体の交流では、「にている」「ちがう」のカードで、考えのズレを全員の目に見えるようにできます。

(7) 4年の重点と、取り違えやすいところ

4年で重点を置くのは、根拠のある予想や仮説を発想する力です（解説 96ページ）。「予想が正しければ（　）はずです」は、5年の重点である解決の方法の発想に近い型です。全員に求めず、えらんで使う型にしました。また、4年生では「理由」と「結果（証拠）」を取り違えやすいことが報告されています（Songer と Gotwals 2012、Yamamoto ほか 2022）。使い始めに、取り違えた例と正しい例を並べて見せると区別しやすくなります。

3 使い方

使い始め（第1〜2時）

  1. 先生が見出しカードと話し方カードを使って、一度やって見せる。
  2. 子どもが班の中で使ってみる。
  3. うまく使えたところを具体的に伝える。
  4. 先生のことばかけを少しずつ減らし、カードに任せる。

型を使うわけも伝えます。たとえば「理由があると、聞く人が納得しやすいから」です。

1時間の中で

  • 流れのカード（1〜5）は黒板の上のはしに貼ったままにし、「いまここ」を今の段階の上に動かす。
  • 見出しカードと話し方カードは、その段階で使う2〜3枚だけを出す。使い終わったら外す。
  • カードは色でなく名前で呼ぶ（「予想のカードを見て」）。
  • 黒板に書く字は白と黄を主にする。

班（5〜6人）で

  • 卓上カードを班に1つ置く。表の順番（ひとりで書く、となりの人に言う、班で全員が話す、書き足す、前で話す人を決める）で進める。
  • 司会は裏の3つのことばで聞き、全員が話したら丸にしるしをつける。
  • 前で話す子は、ノートや白い紙を書画カメラで映し、指さしながら話してもよい。
  • 聞く子は反応カードで「にている」「ちがう」を示す。先生は「ちがう」を上げた子に理由を聞き、考えのズレをはっきりさせる。

外していく目安

同じ型を、2回続けて型を見ずに言えたら、1段外します（全文、書き出しだけ、見出しだけ、なしの順）。この目安は研究の手続きを借りたもので、小学校の理科で確かめた数字ではありません。子どもによっては、型を長く使い続ける配慮が必要な場合もあります。その子にとって一時的な足場か、続ける配慮かを決めておきます。

小さく記録する

型を見ずに言えたか、理由を言えたかを、名簿に丸をつけるだけで記録します。単元の初めと終わりで比べると、型を外すときの判断材料になります。

4 根拠の強さと、見つからなかったこと

  • 通常の学級の4年生が、前に立って理科の予想を説明する場面を、そのまま確かめた研究は見つかりませんでした。この資料の示唆は、近い分野の研究と公的な資料からの推論を含みます。
  • 話し方の型の掲示そのものの効果を、比べて確かめた研究は見つかりませんでした。使いながら記録をとり、確かめていく扱いが適切です。
  • NCAEP の根拠は自閉スペクトラム症の子どもが対象で、多くは少人数の研究です。
  • 教室の掲示の実験（Fisher ほか 2014）は、幼児と、授業に関係のない飾りが対象です。
